# Mitti Somsa: joylash yo'riqnomasi

1. **GitHub**: github.com da yangi repository oching (masalan `mitti-somsa`), shu papkadagi barcha fayllarni (`index.html`, `style.css`, `script.js`, `images` papkasi, `package.json`, `api` papkasi) yuklang. `api` papkasi shunday qolsin.
2. **Vercel**: vercel.com ga GitHub orqali kiring, "Add New > Project" bosib repository'ni tanlang, "Deploy" bosing.
3. **Maxfiy sozlamalar**: Vercel > loyiha > Settings > Environment Variables:
   - `BOT_TOKEN` = BotFather bergan token (hech kimga yubormang)
   - `CHAT_ID` = 5182315918
   Keyin Deployments > oxirgi deploy > Redeploy bosing.
4. **Sinov**: saytdan buyurtma bering. Bot sizga xabar yuborishi kerak (avval botda Start bosgan bo'lishingiz shart).
5. **Domen**: Vercel > Settings > Domains orqali mittisomsa.uz kabi domenni ulang.

Narx yoki menyu o'zgarsa: `index.html` (ITEMS) va `api/order.js` (MENU) ikkalasida bir xil o'zgartiring.
